# Política de memoria y retención

- Particionar cada dato por case_id y obligation_id; nunca unir obligaciones por parecido nominal.
- Eventos episódicos son append-only. Una rectificación crea evento compensatorio y conserva origen.
- Memoria semántica guarda solo hechos validados y enlaces al evento/documento que los sustenta.
- Memoria sistémica conserva versiones y fechas; una norma candidata no se trata como regla vigente.
- Memoria agéntica no almacena emociones, vulnerabilidades, salud, ideología, predicciones de solvencia ni atributos sensibles. Solo resume eventos observables relevantes, con evidencia, confianza, vencimiento y corrección.
- Una preferencia de canal explícitamente declarada puede guardarse como declaración, no como patrón conductual. Para afirmar un patrón repetido de respuesta o promesas se requieren al menos dos eventos independientes y citados.
- Los patrones nunca se usan para intensificar presión, aumentar frecuencia ni seleccionar amenazas o mensajes coercitivos.
- Datos sintéticos no se reutilizan para decisiones reales, contactos ni producción.
- La retención definitiva no está configurada; completar D-08 antes de usar datos no sintéticos.
