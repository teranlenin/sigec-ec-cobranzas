# Contexto de Gemini para STPR

Lee AGENTS.md y activa la Skill pertinente desde .agents/skills/ en Gemini CLI. El proyecto mantiene procedimientos canónicos compatibles con Agent Skills; verifica el descubrimiento con la versión instalada de Gemini CLI.

Modo obligatorio: simulación; datos sintéticos únicamente; nada de llamadas, mensajes o escrituras productivas. Cada borrador lleva “SIMULACIÓN — NO ENVIAR”. Para Gemini Apps, la importación de cada Skill es manual; consulta docs/harness_compatibility.md.
