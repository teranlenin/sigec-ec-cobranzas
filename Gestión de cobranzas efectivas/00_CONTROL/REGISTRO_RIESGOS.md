# Riesgos iniciales y controles

| Riesgo | Control inicial | Pendiente |
|---|---|---|
| Mezclar cartera real y fixtures | Root separado; no copiar datos del padre; fixtures sintéticos | Revisar aportes futuros |
| Norma inexacta o desactualizada | Fuentes candidatas con fechas; abstención | Validación jurídica |
| Perfilado individual invasivo | Señales observables mínimas; excluir emoción/vulnerabilidad | Evaluar finalidad y riesgos |
| Comunicación coercitiva | Solo borrador, revisión, sin envío | Mantener conectores deshabilitados |
| RAG sin soporte suficiente | Citas y abstención obligatorias | Definir umbrales |
| Actualización errónea | Append-only, idempotencia en diseño | Implementar sandbox tras decidir stack |
| Discriminación | Segmentación explicable; excluir atributos sensibles | Auditoría cuantitativa |
| Filtración de datos financieros | Fixtures sin identificadores reales | Revisar controles institucionales |
