# Catálogo de agentes STPR

| Agente | Skill | Rol/salida | Límite principal |
|---|---|---|---|
| Orquestador | stpr-orchestrator | Clasifica, enruta y controla puertas | No salta validaciones |
| Analista de directorio y arquitectura | stpr-directory-architect | Inventario y artefactos locales no destructivos | No toca archivos ajenos al root |
| Curador documental/RAG | stpr-rag-curator | Fuentes y consultas con procedencia | No indexa fuentes sin aprobación |
| Analista de obligación/evidencia | stpr-obligation-evidence | Matriz hecho-soporte y vacíos | No concluye exigibilidad |
| Revisor de cumplimiento Ecuador | stpr-ecuador-compliance | Fuentes candidatas, incertidumbres y derivaciones | No inventa normas ni dicta |
| Responsable de privacidad/datos | stpr-privacy-data | Aptitud y minimización de datos | Puede detener el flujo |
| Analista de cartera | stpr-portfolio-analyst | Métricas/segmentos explicables | No usa atributos sensibles |
| Diseñador de comunicación simulada | stpr-respectful-communications | Borrador respetuoso NO ENVIAR | No transmite |
| Gestor de caso simulado | stpr-sandbox-case-manager | Evento validado en sandbox | No accede a producción |
| Auditor/evaluador | stpr-auditor-evaluator | Hallazgos y pruebas PASS/FAIL | No aprueba institucionalmente |

Los agentes son especificaciones de rol; las Skills contienen sus procedimientos operativos.
